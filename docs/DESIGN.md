# 魔境騎士パラディオン (Makyou Kishi Paradion) 設計書
MZ-1500 / Z80A 3.58MHz / テキスト40x25 + PCG / デュアルPSG (SN76489AN x2)

> 本作は MSX『魔城伝説』に**インスパイアされた**オリジナル作品である。
> グラフィック・キャラクター・ステージ構成・ネーミングはすべて独自デザインであり、
> 版権素材の模倣は行わない。「縦スクロールで自機が 8 方向移動し、地上物を破壊しながら
> 先へ進むシューティング」というジャンル骨格のみを踏襲する。

## 1. メディア構成 (QuickDisk 2段階ロード)

| 面 | ファイル名 | 属性 | ロード先 | 実行先 | 内容 |
|---|---|---|---|---|---|
| A (表) | PARADION A | 01h | 2000h | 2000h | ブートローダ + PCG パターン全 24KB |
| B (裏) | PARADION B | 01h | 1200h | 1200h | ゲーム本体 + マップ/BGM データ |

ロードシーケンス (実機 IPL / EXT.ROM の標準手順に完全準拠):

1. 電源投入 → IPL が A 面先頭ファイルを自動ロードし 2000h から実行
2. ローダが PCG データ 24KB を OUT E5h (B/R/G プレーンバンク 1/2/3) 経由で
   PCG-RAM (D000h-EFFFh 窓, プレーン毎 8KB = 2KB x 4 セグメント) へ LDIR 転送
3. OUT E3h で VRAM モードに復帰 → タイトル + 「B面を入れてCRキー」表示
4. BIOS $001B (INKEY$) でキー待ち → **JP $EA0E** (EXT.ROM の「次ファイルをロード
   して実行」ルーチン) へジャンプ
5. ユーザが B 面に差し替えて CR を押すと $EA0E が B 面のファイルをロードし
   1200h から実行 → ゲーム開始

- 実証参照: 「迷宮への扉」サンプル (A面 0x2000/0x5000, B面 0x1200/0x2C00) が本手順で動作済み
- エミュレータ CLI に `--qd-swap FILE@frame` を追加し、差し替え込みの E2E テストを自動化

## 2. バンク / VRAM / PCG 利用計画

- バンク: 0000h-0FFFh = モニタ ROM (BIOS 呼び出し用, OUT E2h 相当を維持),
  D000h-EFFFh = VRAM & MMIO (OUT E3h)。ゲーム中は PCG モード (E5h/E6h) 不使用
- VRAM: D000h テキストコード / D400h PCG コード / D800h テキスト属性 / DC00h PCG 属性
- 優先度: OUT F0h,03h (PCG 表示 + PCG 前面)。テキストレイヤはスコア欄とメッセージ用
- PCG 属性: プレイフィールド 22 行は一律 08h (バンク0/表示on)。
  スプライト描画時のみ 48h(バンク1) / 88h(バンク2) / C8h(バンク3) を書く。
  → **スクロール時に属性領域のシフトが不要**になる (コスト半減)
- パレット: F1h は恒等写像のまま。色は PCG 3 ビット直指定
  (0=黒 1=青 2=赤 3=マゼンタ 4=緑 5=シアン 6=黄 7=白)

### PCG キャラクタ割当 (1024 文字)

| バンク | 用途 | コード |
|---|---|---|
| 0 | 16x16 地形タイル (5 ステージ x 6 種、各4文字) | 80h-F7h |
| 0 | 数字 0-9 / UI | 50h-5Fh |
| 0 | 破壊可能地形 (各16x16タイルの4象限) | 94h-97h, ACh-AFh, C4h-C7h, DCh-DFh, F4h-F7h |
| 1 | 自機 歩行 2 フレーム x シフト 4 相 (各4文字) | 00h-1Fh |
| 1 | ショット / 敵弾 (8x8) | 20h-21h |
| 1 | 爆発 4 フレーム (16x16) | 22h-31h |
| 1 | パワーアップ 16x16 (ツイン/スピード/シールド/1UP) | 32h-41h |
| 2 | ザコ敵 6 種 (種 N の先頭 = 8*(N-1), 各 2 フレーム) | 00h-2Fh |
| 2 | 宝箱 (16x16, アニメなし) | 30h-33h |
| 3 | ボス 5 種 (32x32 x 2 フレーム, data.asm BOSS_CODE_TBL 参照) | 00h-D0h |

- ★スプライトの黒 (色 0) ピクセルは init_stage 時にステージ別フィールド色
  (STAGE_TABLE +F) へ一括置換される (= 透過色として扱う)。キャラクタは
  黒背景ではなく地形に馴染む。video.asm sprite_recolor_field が PCG-RAM を
  ピクセル単位で直接書換える (ステージ開始時に 1 回だけ, 毎フレームの
  コストはゼロ)。テーブルポインタ (W_RFTBL) とプレーン別置換マスク
  (W_RFMASK) はワーク RAM に退避 (OUT E5h 窓中でも B000 域は通常 RAM)。
- ★面を跨ぐ際は bank1-3 の PCG を元データ (pcg_restore.asm, pcggen 生成
  18KB) で復元してから置換する (置換は一方通行のため, 復元しないと前の面の
  色が透過色のまま残る)。転送と置換は 1 パス統合 (約 0.2 秒 / 面切替時)。
  絵を描く際は黒を輪郭に使わないこと (tools/pcggen.py 冒頭のルール参照)。

### 16x16 スプライト描画 (パターンシフト方式)

- 自機/ザコは 2x2 文字 = 16x16 ドット。移動は 2 ドット刻み
- 水平位置 x の bit1 (2px 単位の位相) でシフト済みパターン 4 相を切替
  (phase = (x >> 1) & 3)。PCG パターン自体を 2/4/6px シフトした絵を A 面に焼き込む
- 描画: D400h の 2x2 セルにコード 4 バイト + DC00h に属性 4 バイト
- 消去: RAM 側プレイフィールドミラー (B000h, 880B) から地形コードを復元
- ミラーは当たり判定 (地形破壊判定) にも使用

### 16x16 ステージ地形

- 各面は固定の20x11タイル配置 (画面幅320px x 高さ176px)。1タイルはPCGコード4個で構成。
- `tools/pcggen.py` のASCII配置を40x22のキャラクタコード表に展開する。乱数配置は行わない。
- 森は川と木橋、岩場は渓谷と石橋、墓地は沼地と朽ち橋、火山は溶岩流と玄武岩橋、
  幻魔城は堀と跳ね橋を配置する。
- 破壊可能タイルはどの象限に弾が当たっても16x16全体を消去する。8pxスクロール中の
  タイル行位相は `W_TILE_PHASE` で管理する。

## 3. タイミングとスクロール設計 (重要)

- CPU ウェイト: 表示期間 (各ライン クロック 0-159) 中の VRAM アクセスは
  H-BLANK (クロック 160) までストール。V-BLANK 中 (ライン 199-261, 約 14,100T) は自由
- ゲームループ: V-BLANK 先頭でスプライト再描画 → V-BLANK 終了待ち → ロジック
- スクロール: 8px (1 キャラ行) 単位。1-2面は17フレーム毎、3-5面は14フレーム毎
  (約0.47-0.59px/フレーム、旧設定の約 70%) に下記を実行 (地形は上端から入って下へ流れる =
  プレイヤーが前進している見た目になる)
  1. D400h 880B を 40B 下へ LDDR (転送先が転送元より後ろにある重なりシフトのため
     後方コピー。表示期間にまたがるが約 0.3-0.4 フレームで完結)
  2. RAM ミラーも同様にシフト (ウェイトなし)
  3. 最上段へマップの次の行を書き込み
  4. 全アクティブオブジェクトを再描画 (スクロールと同フレーム内)
- ボス戦中はスクロール停止 → CPU 余剰をボス演出に充てる

## 4. サウンドドライバ (フレーム駆動)

- V-BLANK 同期メインループから `sound_update` を1フレームに1回呼ぶ (約60Hz)
- `sound_update`: BGM/SE シーケンサを1tick進め、PSG (E9h 両チャンネル同時) へ書き込む。
  SE は要求時に BGM に優先して同一tickへ注入
- 8255 PC2 タイマー割り込みゲートは閉じたまま使用しない
- BGM データ形式: `[継続tick][バイト数][PSGバイト列...]` の連鎖, FFh=終端。
  PSG の矩形波 3 音 (ch0/1/2) と短いノイズ打楽器 (ch3) を使用し、
  各音符で音量レジスタ 90h/B0h/D0h を個別に設定する
- SE データ形式: BGM と同じ `[継続tick][バイト数][PSGバイト列...]` の連鎖。
  ドライバは継続tickを待ってからバイト列を out し (BGM と同一の進行), 00h=終端
- 音色: L=R 同一内容 (E9h デュアルモノラル)。曲ごとの譜面は `tools/musicgen.py`、
  キャラクタのドット絵は `tools/pcggen.py` で管理し、ビルド時にアセンブラデータへ生成

## 5. ステージ構成とゲームバランス (全 5 面自力クリア想定 約 12-15 分)

共通: 残機 REST=2 / ノックバックなし / 復活後 180 フレーム無敵 (自機点滅) /
シールド被弾時 60 フレーム無敵 / 敵撃破 100 点, 破壊ブロック 30 点,
宝箱 200 点, ボス 5000 点 / 10000 点毎に 1UP

| 面 | 名 | 背景 (バンク0) | 道中長 | スクロール間隔 | 敵 spawn 間隔 | 同時雑魚上限 | ボス | HP | 攻撃間隔 |
|---|---|---|---|---|---|---|---|---|---|
| 1 | 魔界の森 | 森 (木/川/木橋) | 45 秒 | 17F | 90F | 2 | 大樹の魔物トレント | 24 | 90F |
| 2 | 荒涼たる岩場 | 岩 (巨岩/渓谷/石橋) | 50 秒 | 17F | 75F | 3 | ストーンゴーレム | 32 | 80F |
| 3 | 呪われた墓地 | 墓地 (墓石/沼/朽ち橋) | 55 秒 | 14F | 65F | 4 | デスサイズ | 40 | 70F |
| 4 | 灼熱の火山 | 火山 (溶岩/黒岩/玄武岩橋) | 60 秒 | 14F | 55F | 5 | 炎の魔竜ファイアドラゴン | 48 | 60F |
| 5 | 幻魔城・最上階 | 城内 (石柱/堀/跳ね橋) | 65 秒 | 14F | 48F | 6 | 幻魔王ダークロード (2 形態) | 56+56 | 50F |

- スクロール間隔 17F/14F は旧値 (12F/10F) の約 70% 速度。雑魚敵と宝箱の降下も
  4 フレームに 1 回移動をスキップし約 75% の速度で動く (出現間隔は据え置き)。
- 雑魚敵: 1 面は 2 体 (種 1-2) から始まり, 面が進むごとに同時上限と種類プールが
  +1 (5 面で 6 体 / 種 1-6)。新しい雑魭が面毎に 1 種追加される。
  種の奇偶で移動パターンが決まる (奇数 = ガーゴイル型, 偶数 = ウィスプ型)。
  敵弾速は 3 面から 2→3px。敵はアイテムを落とさない。
- 宝箱: 約 4 秒毎に上から降下する (画面内 1 個, 取り逃すと画面下で消滅)。
  ショットを当てると爆発 + 200 点 + ランダムなパワーアップが出現する。
- パワーアップは宝箱を撃ち抜いた位置に出現し移動しない。寿命 240 フレーム
  (約 4 秒) で消滅する。
- ボス攻撃: 照準弾 3 発 (中央 / 左右) を自機へ向かって発射する。x 差が大きい
  弾は 2 倍速 (attr bit3) で飛ぶ。
- 破壊ブロック: ショット 2 発で破壊。破壊で 30 点 (パワーアップは出ない)
- パワーアップ (16x16 アイコン, 取得で効果音 + アイテム名を画面中央に表示):
  - ツインショット (2Way 化) / スピードアップ (移動 2px→4px) / シールド (1 回被弾無効) /
    1UP。被弾するとパワーアップは全喪失 (魔城伝説系の緊張感を維持)
- ボス共通: 画面上部に降下 → 水平往復 → 照準弾。5 種の PCG は
  data.asm BOSS_CODE_TBL (0x00/0x40/0x80/0xC0/0x20) をステージ番号で参照。
  HP 半減で行動速度 1.3 倍 (第 5 面のみ形態変化: 0x20 系 → 0xA0 系へ差し替え)
- 中央メッセージ (テキストレイヤ / 0FFh 終端, 00h = 空白。表示中は文字セル
  だけ PCG を非表示にし, 色属性 (0D800h+) の背景をフィールド色へ変更する
  = 黒帯を作らず地形が見えたまま文字だけ浮く。空白セルは地形表示のまま。
  スプライト消去パスが属性を戻すため毎フレーム再 assert する):
  GAME START (起動時) / STAGE n / READY (復活時) / STAGE CLEAR /
  GAME OVER + PUSH C KEY / アイテム名 (行 8, 1.5 秒)
- コンティニュー: ゲームオーバー後 C キーでスコア 0 リセット & 現面の最初から

## 6. 画面構成 (40x25)

```
行 0-21   プレイフィールド (PCG バンク0 地形 + スプライト)
行 22     仕切り (ブランク)
行 23     SCORE 000000   HI 000000   REST x   STAGE x
行 24     (ラベル: テキストレイヤ FONT ROM / 数値: PCG 数字タイル)
```

## 7. ビルド & テスト

- アセンブラ: z88dk z80asm (`z80asm -b -mz80 -l`)
- パッケージ: `tools/mkmzt.py` (128 バイト MZT ヘッダ + 本体)
- PCG/マップ生成: `tools/pcggen.py` (ASCII アートと20x11固定配置 → 3プレーン/40x22 DBソース)
- BGM 生成: `tools/musicgen.py` (音符譜面 → 3 音 + ノイズの PSG ストリーム)。
  1面は森の冒険曲、2面は岩場のリフ、3-5面は墓地/城の曲、ボス戦と勝利曲も個別に用意。
- E2E: `dotnet run --project src\Mz1500.Cli -c Release -- --roms romsample
  --qd out\ParadionA.mzt --qd-swap out\ParadionB.mzt@<F> --key D@<F2>
  --frames N --ppm out\frame.ppm --wav out\game.wav`
- GUI: `Mz1500.Gui.exe out\ParadionA.mzt` → 起動 → ウィンドウへ ParadionB.mzt を
  ドラッグ&ドロップ → CR キー
